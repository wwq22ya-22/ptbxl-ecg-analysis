## 最短运行方式

在 PowerShell 中：

```powershell
cd D:\MyProject\college\ecg1
```

启动可视化页面：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app\streamlit_app.py
```

浏览器打开 `http://localhost:8501/`。

启动 API：

```powershell
.\.venv\Scripts\python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

接口文档位于 `http://127.0.0.1:8000/docs`。两个服务需要分别占用一个终端。

单条真实记录推理：

```powershell
.\.venv\Scripts\python.exe scripts\predict_record.py --ecg-id 9
```

最终回归测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp D:\MyProject\college\ecg1\outputs\pytest-run
```

指定 `--basetemp` 是为了避开当前 Windows 中文用户名临时目录的权限异常。测试结束后，`outputs\pytest-run` 可以删除。

## 已知边界

- 模型性能来自 PTB-XL 官方 test fold，尚无独立医院数据上的正式指标。
- R 峰、短时 HRV 和模型响应图用于算法演示，未做医疗器械级验证。
- 系统不得用于临床诊断或治疗决策。
- Chapman 外部验证代码保留在 `scripts/evaluate_external_chapman.py` 和 `src/external_validation/chapman.py`，以后下载数据后可继续。
