# 基于 PTB-XL 的十二导联 ECG 智能分析与可视化系统：项目总结

更新日期：2026-09-27

## 一、项目简介

本项目使用 PTB-XL 十二导联心电图数据，实现真实 ECG 数据读取、信号预处理与基础量测、五类多标签模型训练和评估、单条心电图推理、Streamlit 可视化页面及 FastAPI 接口。项目定位为课程展示与算法工程实验，不用于临床诊断或治疗决策。

## 二、数据与输入规格

- 数据集：PTB-XL v1.0.3，官方 100 Hz WFDB 记录。
- 数据规模：共 21,799 条记录；训练 fold 1–8 为 17,418 条，验证 fold 9 为 2,183 条，测试 fold 10 为 2,198 条；按患者划分，患者不会跨集合。
- 单条输入：10 秒、12 导联、100 Hz；模型张量形状为 [B, 12, 1000]，物理信号单位 mV。
- 分类标签：NORM（正常）、MI（心肌梗死）、STTC（ST/T 波改变）、CD（传导异常）、HYP（肥厚）。采用多标签任务，一条记录可对应多个类别。
- 当前 PTB-XL 数据目录：D:\datasets\ptb-xl。实际文件约 43,602 个、551,244,533 字节（约 525.7 MiB，包含波形与元数据）。

测试集阈值由验证集确定；测试集不参与训练、早停或阈值选择。

## 三、信号处理与基础量测

训练与推理统一使用相同预处理配置：

- 基线漂移估计：0.2 秒和 0.6 秒双中值滤波。
- 低通/高通组合带通：0.5–40 Hz、四阶零相位 Butterworth。
- 归一化：逐记录 z-score；工频陷波可配置，本次配置未启用。
- R 峰检测：Pan–Tompkins 风格的带通、微分能量、滑动积分和自适应候选峰筛选；另含 T 波抑制与 RR 生理范围检查。
- 基础量测：R 峰、RR 间期、心率和短时 HRV。HRV 数值仅用于 10 秒信号演示，不等同于临床长程 HRV 评估。

## 四、模型结构与文件大小

两个分类器均接收 [B, 12, 1000]，输出 [B, 5] 五个独立类别 logit；推理时逐类使用 sigmoid，并与验证集选定阈值比较。

| 项目 | CNN 1D | ResNet1D |
| --- | --- | --- |
| 网络主体 | 4 个 Conv1D 块，通道 12→32→64→128→128；卷积核 15、7、5、3；每块含 BatchNorm、ReLU 和最大池化 | 32 通道 stem；5 个双卷积残差块，通道 32、32、64、64、128、128；主分支卷积核 7 与 5，必要时用投影捷径匹配维度 |
| 分类头 | 自适应全局平均池化、Dropout 0.2、线性层 128→5 | 自适应全局平均池化、Dropout 0.2、线性层 128→5 |
| 可训练参数 | 111,557 | 450,885 |
| 纯模型 state_dict 张量大小 | 449,076 字节，约 438.6 KiB | 1,812,092 字节，约 1.73 MiB |
| 正式 checkpoint 文件 | baseline_best.pt：1,364,951 字节，约 1.30 MiB | resnet1d_best.pt：5,481,641 字节，约 5.23 MiB |
| 正式文件路径 | outputs/checkpoints/baseline_best.pt | outputs/checkpoints/resnet1d_best.pt |

Checkpoint 除模型参数外还包含优化器状态、epoch、训练与验证规模、阈值、预处理配置、标签顺序和评估摘要，因此文件比纯模型参数张量大。baseline_smoke.pt 为 1,364,951 字节，是小样本流程检查模型，不是正式性能结果。

## 五、训练配置

- 固定随机种子：42。
- 最大训练轮次：20；batch size：32。
- 学习率：0.001；weight decay：0.0001。
- 使用自动混合精度 AMP、训练集类别权重、验证集 AUROC 选最佳 epoch、验证集逐类 F1 选阈值和 early stopping（patience 5）。
- CNN 与 ResNet1D 均在 RTX 4060 Laptop GPU 上完成正式训练；模型结果是各自一次训练的实验结果。
- 两个模型均在第 11 轮达到最佳验证结果，训练在第 16 轮早停。

## 六、正式测试结果

PTB-XL 官方测试 fold 共 2,198 条记录，以下为已保存 JSON 中的指标：

| 模型       | Macro AUROC | Macro F1 |  测试记录 |
| -------- | ----------: | -------: | ----: |
| CNN 1D   |      0.9077 |   0.7080 | 2,198 |
| ResNet1D |      0.9120 |   0.7149 | 2,198 |

逐类别结果如下，括号内为该类阳性支持数：

| 类别 | CNN AUROC / F1 | ResNet1D AUROC / F1 | 支持数 |
| --- | ---: | ---: | ---: |
| NORM | 0.9391 / 0.8503 | 0.9430 / 0.8560 | 963 |
| MI | 0.9144 / 0.7368 | 0.9180 / 0.7409 | 550 |
| STTC | 0.9293 / 0.7521 | 0.9312 / 0.7540 | 521 |
| CD | 0.9157 / 0.7404 | 0.9219 / 0.7426 | 496 |
| HYP | 0.8400 / 0.4603 | 0.8456 / 0.4809 | 262 |

ResNet1D 在这次单次实验中的汇总分数略高，不足以说明它稳定优于 CNN。HYP 的 F1 明显低于其他类别；汇报模型能力时应保留这一结果和单数据集、单次训练的边界。

结果文件：

- ResNet1D 指标：outputs/metrics/test_metrics_resnet1d_full.json
- 逐条预测：outputs/predictions/
- 训练曲线、ROC、混淆矩阵及类别分布图：outputs/figures/
- 检查点：outputs/checkpoints/

## 七、应用功能与验证

- Streamlit：概览、十二导联波形、Lead II 处理和 R 峰、分类结果、模型响应区域、测试性能六个标签页；支持 CNN 与 ResNet1D 选择。
- FastAPI：GET /health 检查服务、模型和设备；POST /predict 接收 100 Hz、12 导联、mV 信号，返回五类概率、阈值和预测标签。
- 真实数据验证：已用 ECG ID 1 和 ID 9 执行读取及推理；ID 9 API 结果与命令行推理一致，页面自动化检查无运行异常。
- 最终测试：35 passed，1 条既有 Starlette/httpx 弃用警告。
- 项目环境：.venv，Python 3.14.3，PyTorch 2.12.1+cu126；最近测得虚拟环境约 4.66 GiB。环境由 Python venv 创建，因此不会出现在 conda env list 中。

## 八、运行命令

项目根目录：D:\MyProject\college\ecg1

启动网页：

    .\.venv\Scripts\python.exe -m streamlit run app\streamlit_app.py

打开 http://localhost:8501/。

单条记录推理：

    .\.venv\Scripts\python.exe scripts\predict_record.py --ecg-id 9

启动 API：

    .\.venv\Scripts\python.exe -m uvicorn api.main:app --host 127.0.0.1 --port 8000

接口文档：http://127.0.0.1:8000/docs。

运行完整测试：

    .\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp D:\MyProject\college\ecg1\outputs\pytest-run

显式指定 pytest 临时目录用于避开当前 Windows 用户系统临时目录的权限问题；测试完成后 outputs\pytest-run 可删除。
